# CTX-0001 - Revolis bus context

## Summary

The bus is a coordination layer, not a replacement for existing Revolis memory.
Long-lived project state remains in `memory/` and formal reports remain in
`docs/reports/` when a task produces durable evidence.

## Rules to preserve

- One PR equals one logical change.
- Commit only reviewed task scope.
- Do not merge, deploy, mutate production data, or contact external parties
  without explicit GO.
- Keep customer data confidential.
- Prefer evidence from files, commands, CI, smoke tests, or production logs over
  unsupported assertions.

## Bus usage

Use `.ai/bus` for narrow handoffs between agents:

- what was requested,
- what was observed,
- what changed,
- what gate is required next.
