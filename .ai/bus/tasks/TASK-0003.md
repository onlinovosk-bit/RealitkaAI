# TASK-0003 — Branch cleanup evidence pack (NEEDS-EVIDENCE)

uspokojiť sa.

## Evidence pack — povinné pred akýmkoľvek delete GO

1. **Full clone** (nie shallow) — explicitne dokázať `git rev-parse --is-shallow-repository = false` a že predchádzajúci Cursor beh bežal / nebežal na shallow.
2. **Tip SHA pre všetkých N kandidátov** — `git rev-parse refs/remotes/origin/<branch>` (alebo ekvivalent) pre každý kandidát; výstup do artefaktu v repe.
3. **Zálohové refs na origin** — pred delete pushnúť:
   `refs/cleanup/2026-08-21/<branch>` → tip SHA (obnova = jeden `git push origin refs/cleanup/...:refs/heads/<branch>`).
4. **Znova `git cherry` / ancestry check na celej množine** proti aktuálnemu `origin/main` (nie na vzorke).
5. **Politika hraničných prípadov** (zapísaná pred delete):
   - zatvorené-nezmergované PR
   - tagované vetvy
   - chránené vetvy (`main`, default, rules)
   - vetvy s open PR
   - vetvy s tip SHA ≠ SHA zo snapshotu evidence packu (poskočenie medzi analýzou a delete)

## Explicitné zákazy

- Žiadne `git push --delete` / GitHub branch delete bez founder GO na evidence pack.
- Žiadne „metóda obstála“ z <100 % overenia kandidátov.
- Žiadny rebase starých cleanup PRs ako náhrada evidence.

## Done when

- Report v `docs/reports/` + bus outbox s tip SHA tabuľkou (N = N), shallow=false dôkaz, backup refs pushed (alebo dry-run zoznam pripravený na GO push), cherry výsledok na celej množine, edge-case policy.
- Founder GO na delete (samostatná brána).
