# Revolis Project OS

Register, kam patrí práca. Pravidlá, ako sa práca robí, ostávajú tam, kde už sú.

Project OS zaraďuje úlohu do trvalej oblasti, ukáže existujúci skill alebo pravidlo a pripomenie bránu súhlasu foundera. Je to rozcestník pre Cursor, Claude Code a Grok. Nie je to druhý prompt systém, ústava ani denník rozhodnutí.
