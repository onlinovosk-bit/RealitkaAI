## Auth + tenant isolation + data URL limity

### Auth (FAKT — PASS v kóde)

1. Flag off → 404 **pred** auth.
2. `createClient()` + `auth.getUser()` → 401.
3. `profiles.agency_id` → 403 `Missing agency_id`.
4. Rate limit `checkAiRateLimit(user.id, "listing-from-photos", 10)`.

### URL fotiek len z tenant property (FAKT — PASS s poznámkou)

- URL vetva vyžaduje `propertyId`.
- `createServiceRoleClient()` + `properties.select(id, images, agency_id).eq(id).eq(agency_id)` — filter tenanta **v query**, nie len v JS.
- Cudzia URL → 403, testnuté; spend sa pri 403 **nevolá**.
- Data URL táto allowlist **neobchádza property tabuľku** — sú to uploady od prihláseného usera. To je iný threat model (obsah fotky), nie cross-tenant CDN.

Service-role tu obchádza RLS zámerne; izolácia drží len kým ostane `.eq("agency_id", agencyId)`. Bez toho by service-role čítal všetky properties.

### Limity data URL (FAKT)

- Max 6 fotiek, 4 MB/ks, MIME jpeg/png/webp/gif, regex base64.
- Loopback / RFC1918 / link-local zablokované. IPv6 ULA `fc00::/7` **nie** — FLAG, nie must-fix.
- UI FileReader kontroluje `file.size` aj MIME pred POST.

Vercel/Next body size (typicky ~4.5 MB) vs 6×4 MB: **NEOVERENÉ** — oversized cez sieť môže padnúť 413 skôr než 400 z validátora. Test na to nie je.

## AI kredity — raz, nie pri zlyhaní, anti double-charge

`CREDITS_ENFORCEMENT` default **off** (`spend-for-action.ts`): `charged: false`, akcia prejde zadarmo. PR text: „Voliteľne neskôr: `CREDITS_ENFORCEMENT=enforce`.“

Keď (a to je cesta GO na ostré účtovanie):

1. `spendForAction` sa volá **pred** `generateListingContentFromPhotos`.
2. Catch 503/502 **nemá refund** a **nemá** `spend` až po úspechu.
3. Idempotency key = sha256 JSON `{property, persona, photos, propertyId}` prefix `listing_from_photos:${user.id}:`.
   - Rovnaký payload retry → `spend_credits` `skipped` (ak RPC tak spraví) — **anti double-charge na identickom retry PASS**.
   - Iný data URL / dvojklik s iným JSON → **druhý charge**.
   - Dva succéssful generate pri enforce + rovnaký kľúč: kredit raz, **dva** Anthropic call — FLAG.

**FAIL účtovného kontraktu (must-fix pred `enforce`):** zlyhanie providera po strhnutí = účtované bez výstupu.

Default off zmierňuje PROD dnes, **neschováva** chybu v kóde, ktorý PR pridáva.
