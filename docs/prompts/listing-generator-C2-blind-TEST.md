# C2 — Slepý preberací test (listing generator)

**Čo:** Porovnaj Text A a Text B. Hádaj **ktorý preferuješ** / **ktorý je ľudský**.
**Kľúč:** `docs/prompts/listing-generator-C2-blind-KEY.md` — **otvor až po hádani**.

---

## Protokol

Pre každý pár (Teriakovce, potom Ľubotice):

1. Prečítaj Text A a Text B (bez hľadania v iných súboroch).
2. Odpovedz:
   - Ktorý text **preferuješ**? (A / B / nerozoznám)
   - Ktorý je podľa teba **ľudský**? (A / B / nerozoznám)
3. Ak spoznáš ľudský na prvý pohľad → napíš **ČO prezradilo**.

### Kritérium C2

| Výsledok | Verdikt |
|---|---|
| Nerozoznáš, alebo preferuješ promptovú verziu | **C2 PASS** |
| Ľudský spoznáš na prvý pohľad | **C2 FAIL** + čo prezradilo |

Po hádani napíš do chatu: PASS/FAIL (+ čo prezradilo, ak FAIL).
