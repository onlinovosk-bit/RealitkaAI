# Lane B — Competition / switching reasons

## Decisions
1. **Primary SK incumbent for low-cost CRM+portal export: backOFFICE (+ ZRKS API/membership fees)** — publicly priced; total cost >> headline 95 EUR/year software fee.
2. **Realsoft successor is Nehnuteľnosti Admin (United Classifieds)** — not a drop-in independent CRM; migration pain is a switching window AND a lock-in risk.
3. **Realman is CZ-primary SaaS** — treat CZ prices as reference, not proven SK list price / localization.
4. **Control alternative: Excel + portal admin + occasional export tool** remains credible for small offices — Revolis must beat switching cost with outcome (leads/time), not feature checklist.
5. **Willingness-to-pay: NOT proven by web** — only hypothesizable vs Revolis seat stack.
